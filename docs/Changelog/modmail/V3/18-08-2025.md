# Support System V3
[Original Message](https://discord.com/channels/1113111089350197380/1316771964487995462/1407057586397646858)

Several bugs have been fixed. Ticket ratings are now also available in the ticket system. Team members can now rename tickets in both the ticket system and Modmail (if enabled). Once renamed, the ticket name will remain unchanged, even if the ticket is moved between categories.
