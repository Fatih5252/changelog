# Support-System V3 (or "Modmail V3")
[Original Message](https://discord.com/channels/1113111089350197380/1316771964487995462/1405632430962114570)

Many errors and issues have been resolved. An option has been added that allows the use of ticket buttons in the ticket system even when there are fewer than five ticket topics. Modmail team member reminders will now (if not disabled) only be sent during opening hours. Team rating messages in Modmail have been improved. The ticket ID generation format can now be customized (e.g., with prefixes or random IDs instead of sequential numbering). Additional bug fixes and improvements have been made.
