# Support-System V3
[Original Message](https://discord.com/channels/1113111089350197380/1316771964487995462/1406673963643572345)

Several bugs have been resolved. Buttons to change a ticket’s topic have been added, they are automatically visible in Modmail but must be enabled in the ticket system. Statistics are now available for both Modmail and the ticket system, with a combined overview if both are active. If a user leaves the server while having an open ticket in the ticket system, it can now optionally be closed automatically. If this option is not enabled and the user later rejoins the server, they will automatically regain access to their ticket. Inactivity reminders have also been added to the ticket system, and tickets can now be closed automatically if users remain inactive for too long.
