# Support-System V3 (or "Modmail V3")
[Original Message](https://discord.com/channels/1113111089350197380/1316771964487995462/1406364016959553687)

Certain ticket topics (in both Modmail and the ticket system) can now override the default ticket channel format. This makes it possible to use names such as "❗-ticket-123" for a bug report or "⭐-ticket-219" for a partnership, making the ticket category instantly recognizable to everyone from the channel name.
