# Support-System V3 (oder "Modmail V3")
[Nachricht](https://ptb.discord.com/channels/489786377261678592/916460015815127081/1405631849585180742)

Viele Fehler und Probleme wurden behoben. Es wurde eine Option hinzugefügt, die die Nutzung von Ticket-Buttons im Ticketsystem auch bei weniger als fünf Ticket-Themen ermöglicht. Erinnerungen für Modmail-Teammitglieder werden nun (sofern nicht deaktiviert) nur während der Öffnungszeiten versendet. Die Team-Bewertungen in Modmail wurden verbessert. Das Format zur Generierung von Ticket-IDs kann jetzt angepasst werden (z. B. mit Präfixen oder zufälligen IDs statt fortlaufender Nummerierung). Weitere Fehlerbehebungen und Optimierungen wurden durchgeführt.
