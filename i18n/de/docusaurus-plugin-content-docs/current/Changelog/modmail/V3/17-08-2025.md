# Support-System V3
[Nachricht](https://discord.com/channels/489786377261678592/916460015815127081/1406673814607368282)

Mehrere Fehler wurden behoben. Es wurden Buttons hinzugefügt, mit denen das Ticket-Thema geändert werden kann in Modmail sind sie automatisch sichtbar, im Ticketsystem müssen sie jedoch aktiviert werden. Statistiken sind nun sowohl für Modmail als auch für das Ticketsystem verfügbar, mit einer kombinierten Übersicht, wenn beide aktiviert sind. Verlässt ein Nutzer den Server, während er noch ein offenes Ticket im Ticketsystem hat, kann dieses nun optional automatisch geschlossen werden. Ist diese Option deaktiviert und der Nutzer tritt dem Server später wieder bei, erhält er automatisch erneut Zugriff auf sein Ticket. Außerdem wurden Inaktivitäts-Erinnerungen für das Ticketsystem hinzugefügt, und Tickets können nun automatisch geschlossen werden, wenn Nutzer über einen längeren Zeitraum inaktiv bleiben.
