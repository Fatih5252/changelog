# Support-System V3 (oder "Modmail V3")
[Nachricht](https://discord.com/channels/489786377261678592/916460015815127081/1406363684950769786)

Bestimmte Ticket-Themen (sowohl in Modmail als auch im Ticketsystem) können nun das Standardformat für Ticket-Kanalnamen überschreiben. Dadurch ist es möglich, Namen wie „❗-ticket-123“ für einen Bugreport oder „⭐-ticket-219“ für eine Partnerschaft zu verwenden, sodass die Ticket-Kategorie für alle sofort am Kanalnamen erkennbar ist.
